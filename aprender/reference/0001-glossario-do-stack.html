Backend — o que você realmente usa

Seis bibliotecas fazem o trabalho todo. Se alguém perguntar “qual é o seu stack de backend?”, a resposta é esta tabela.

BibliotecaO que éOnde aparece no seu código
fastapiFramework web. Define rotas, valida entrada, serializa saída, gera documentação automática em /docs.app = FastAPI(), todos os @app.get e @app.post em api.py
uvicornServidor ASGI. É o processo que escuta a porta 8000 e fala HTTP. FastAPI sozinho não atende ninguém.uvicorn.run(app, host="127.0.0.1", port=8000), no fim de api.py
pydanticValidação de dados por tipo. Transforma anotações Python em contrato executável.CharacterCreationRequest, UserAction, LoadRequest
sqlalchemyORM. Traduz classes Python ↔ tabelas SQL, e gerencia sessões e transações.database.py inteiro; toda linha com db.query(...) ou db.commit()
groqSDK do provedor de inferência. Cliente HTTP tipado para o endpoint de chat.client = Groq(api_key=...) e client.chat.completions.create(...)
python-dotenvLê o arquivo .env e injeta nas variáveis de ambiente, para a chave de API não ficar no código.load_dotenv() no topo de api.py
requestsCliente HTTP clássico e síncrono.Só em g.py, o script que baixou as artes dos personagens
SQLite não está na lista — e está certoSQLite vem embutido no próprio Python (módulo sqlite3). Você não instala; ele já está lá. Por isso "sqlite:///./rpg_save.db" funciona sem nenhuma dependência extra.

Backend — as que sobraram

Estas apontam para uma fase anterior do projeto, quando você usava a API do Google. Hoje nenhuma linha do código as importa.

PacoteSituação
google-ai-generativelanguage, google-api-python-client, google-auth, google-auth-httplib2, googleapis-common-protosmorto SDK do Gemini. Resquício de antes da migração para o Groq.
grpcio, grpcio-status, protobuf, proto-plus, cachetools, pyasn1, rsa, httplib2, uritemplate, pyparsingmorto Dependências dos pacotes acima. Somem junto.
tqdmmorto Barra de progresso. Nenhum import no projeto.
Dois problemas concretos no requirements.txt 1. Está salvo em UTF-16. Foi gerado com pip freeze > requirements.txt no PowerShell, que grava nesse encoding. Em outra máquina (ou num Docker), o pip install -r pode simplesmente não conseguir ler o arquivo. Regere com pip freeze | Out-File -Encoding utf8 requirements.txt.
2. É um freeze, não uma lista de intenção. Quem lê não distingue o que você escolheu do que veio de carona. O padrão profissional é declarar só as diretas (em pyproject.toml ou num requirements.in) e deixar a resolução para a ferramenta — uv ou pip-tools.

Frontend — ferramentas de desenvolvimento

Nada aqui vai para o navegador do usuário. São ferramentas que rodam na sua máquina.

FerramentaPapel
vite + @vitejs/plugin-reactServidor de desenvolvimento e empacotador. Dá o hot reload (salvou, a tela atualiza) e, no build, junta e minifica tudo para produção.
typescriptJavaScript com tipos. Roda no build (tsc -b) e no editor; o navegador nunca vê TypeScript.
tailwindcss + postcss + autoprefixerCSS por classes utilitárias — é a razão de className="flex h-screen bg-black". O PostCSS processa e o Autoprefixer adiciona prefixos de navegador.
eslint + plugins + typescript-eslintAnalisador estático: aponta erros e maus hábitos antes de rodar. Você tem configurado (npm run lint) mas provavelmente nunca rodou.
@types/react, @types/node…Definições de tipo para bibliotecas escritas em JavaScript puro. Só existem para o TypeScript entender.

Vocabulário

Os termos que aparecem nas lições. Use exatamente estes — inclusive em entrevista.

TermoDefinição
ASGIA interface padrão entre um servidor Python e uma aplicação web assíncrona. Uvicorn implementa o lado do servidor; FastAPI, o lado da aplicação.
ORMObject-Relational Mapper. Camada que traduz entre objetos de uma linguagem e tabelas relacionais. No seu caso: HeroModel ↔ tabela herois.
Sessão (do ORM)A unidade de trabalho do SQLAlchemy. Acumula alterações em memória e as escreve no banco de uma vez, no commit(). Não confundir com “sessão do jogo”.
Endpoint / rotaUm par método + caminho (POST /chat) ligado a uma função. É a unidade de API.
Injeção de dependênciaO framework constrói e entrega o que a sua função precisa, em vez de a função ir buscar. É o Depends(get_db).
CORSRegra do navegador que bloqueia chamadas entre origens diferentes. Seu front (porta 5173) e seu back (8000) são origens distintas — daí o CORSMiddleware. allow_origins=["*"] desliga a proteção; serve para desenvolver, não para produção.
Prompt de sistemaA mensagem de papel system, que estabelece o comportamento do modelo. No Mestre.IA é a biblia_mestre.txt mais o estado atual do jogo.
TokenA unidade em que o modelo lê e escreve — mais ou menos um pedaço de palavra. É a unidade de cobrança e o que enche a janela de contexto.
Janela de contextoO máximo de tokens que o modelo aceita numa chamada. Tudo que você quer que ele considere precisa caber ali — daí a necessidade de escolher o que enviar.
Modo JSONAjuste do provedor que restringe a geração a JSON sintaticamente válido. Garante que dá para fazer json.loads; não garante que os campos que você pediu vieram.
Estado (React)Dado que, ao mudar, faz o componente ser redesenhado. Criado com useState.
Efeito (React)Código que roda depois do desenho, para falar com o mundo externo — uma chamada de API, por exemplo. É o useEffect.
SPASingle Page Application. Uma página HTML só; a navegação troca componentes em JavaScript sem recarregar. É o que o react-router faz.
